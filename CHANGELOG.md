# Changelog

All notable changes to Solenoid Calculator are documented in this file.

## [0.1.0] - 2026-11-16

Initial public beta release.

- Validated calculation core for thick cylindrical air-core solenoids.
- Simple-cubic winding geometry retaining requested and effective dimensions.
- Homogeneous azimuthal current-density model for the axial magnetic field.
- DC wire resistance and numerically integrated DC self-inductance.
- Ideal low-frequency series impedance from resistance and inductance.
- Frozen reference cases and regression tests for the scientific model.
- Browser-native Shiny/Shinylive interface with local calculations.
- Documentation of model assumptions, equations, and implementation choices.
